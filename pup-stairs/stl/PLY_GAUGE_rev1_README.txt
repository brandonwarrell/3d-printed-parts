PLY_GAUGE rev1 — plywood thickness gauge (workshop tool)
========================================================

WHAT IT ANSWERS: which slot slides snug onto the edge of a ProWood 1/4 in
panel = the panel's true thickness. No caliper reading needed.

PRINT: PLA is fine (it's a tool, not a final). Flat as exported, no
supports, no brim needed. ~16 g PLA, ~25 min. 3+ perimeters.

USE: push each slot onto a bare panel edge (not a cut edge with fuzz —
factory edge, mid-panel).
  - Slot slides on with light push, no wiggle  -> that's your PLY_T
  - Between sizes (one forces, next wiggles)   -> PLY_T = halfway
The EAR TAB marks the 5.0 mm end; slots go 5.0 / 5.2 / 5.4 / 5.6 / 5.8 /
6.0 / 6.2 from the tab.

REPORT BACK: "slot X.X snug" (or "X.X forces, X.X wiggles").
This sets SLOT_W for the ALIGN-JIG and any future slotted part.
