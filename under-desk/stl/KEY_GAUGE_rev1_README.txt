KEY-GAUGE rev1 — power-strip keyhole fit gauge
==============================================

PRINT: ABS, 0.2mm layers, no supports, print AS ORIENTED (heads on bed).
~9g, ~25min. Brim recommended (small footprint parts, ABS).

USE:
1. Snap all 6 studs off the sprue frame.
2. Count the pips on each stud's top edge — that's its number (1-6).
3. For each stud: push the HEAD into a keyhole's big round end, then
   slide it toward the narrow slot end, like hanging a picture frame.
4. Judge the fit:
   - head won't enter the round hole
   - enters, but won't slide into the slot (shank too fat)
   - slides and locks SNUG (little/no wobble)  <-- the winner
   - slides but wobbles / rattles loosely

REPORT BACK like: "4 is snug, 2 slides but wobbles, 6 won't slide."
Best single answer = the snuggest stud number. If NOTHING enters the
round holes, or everything rattles, say that — rev2 shifts the sizes.

STUD TABLE (pips -> shank dia / panel gap, mm):
  1 = 3.5 / 2.5
  2 = 4.0 / 2.5
  3 = 4.0 / 3.5
  4 = 4.5 / 2.5
  5 = 4.5 / 3.5
  6 = 5.0 / 3.0

The winning stud tells us the screw size AND how proud to drive it in
the desk leg. TEMPLATE-1 and KEEPER-1 generate from that answer.
Same-filament rule: this calibration is valid for the ABS + slicer
profile you print it with — print the later parts with the same.
